# AGENTS.md

Coding agents other than Claude Code: read [CLAUDE.md](CLAUDE.md) and follow it as if it were written for you. It is the single source for this repository: Part 1 covers working in the code (commands, file map, project rules, testing without network) and Part 2 is the install runbook to follow when the user asks to build, install, set up or deploy the bot ("build me the app", "תבנה לי את האפליקציה"). Its hard rules bind you too: never ask the user to paste a key into the chat and never print a key's value, never finish an install while the bot is open with a warning without asking the user explicitly, speak to the user in their language, and run lint, typecheck and tests (`npm run check`) before changing code. This file stays a pointer; put any new instruction in CLAUDE.md.
